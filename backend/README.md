# Food API

The API is served from `/api/foods`.

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/api/foods` | List all foods |
| GET | `/api/foods/search?q=...` | Search `name`, `foodId`, `category`, `cuisine`, and `ingredients` (case-insensitive substring match) |
| GET | `/api/foods/:id` | Get a food by `foodId` or MongoDB `_id` |
| POST | `/api/foods` | Create a food; `foodId` is generated by the server |
| PUT | `/api/foods/:id` | Update a food by `foodId` or MongoDB `_id` |
| DELETE | `/api/foods/:id` | Delete a food by `foodId` or MongoDB `_id` |

Successful responses contain `success: true` and the result in `data`. Errors contain `success: false` and a `message`. Search requires the `q` query parameter.

Do not include `foodId` when creating or updating a food. New foods receive a unique `FOOD-<UUID>` identifier from the server, and the identifier cannot be changed through the API.
